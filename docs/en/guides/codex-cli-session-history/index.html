CODEX CLI · CONVERSATION HISTORY

Search Codex CLI history without replaying old commands

A Codex CLI session may contain tool output, shell commands, debugging steps, and decisions made during a coding task. Instead of remembering individual session names, you can index supported local records and search their original context.

Download AIKS ↗ See supported sources

Where are Codex CLI sessions stored?

A typical Codex CLI installation saves local sessions under a user data folder, commonly ~/.codex/sessions/. The path can vary with versions and settings such as CODEX_HOME. AIKS reads supported local record formats; it does not use account credentials to download private cloud conversation histories.

~/.codex/sessions/

How to search and reuse the records

  1. Inspect the Codex CLI provider

    Find Codex CLI in Data Sources. Confirm that the detected location is the session data directory, not the application install folder.

  2. Import the work history

    Run a read-only scan, then filter Work Records by Codex CLI. Check the original conversation and processing status separately; imported is not the same as extracted.

  3. Search an error or project

    Try an exception message, function name, shell command, or repository-specific term, then open the source session to review context.

  4. Keep verifiable findings

    Optionally configure extraction to save a specific fix and its supporting source. Embedding-based search is not required for browsing and keyword search.

Why search across tools?

A task may start in Codex CLI and continue in Claude Code or Cursor. A shared view makes it easier to locate related material, but AIKS should not infer that similar conversations prove identical facts.

Compatibility and privacy boundaries

  • This guide covers supported local Codex CLI records, not every historical event format or private cloud account export.
  • Scanning is read-only and does not replay old shell commands or tools.
  • AI extraction requires explicit model configuration; local and remote endpoints are user choices.

Check actual parser coverage rather than assuming every tool version is supported. Provider compatibility matrix.

Frequently asked questions

Why are older Codex sessions missing?

Check the user account, any CODEX_HOME override, the provider's detected directory and supported file layouts.

Will the importer rerun the commands from a session?

No. It reads historical messages and metadata without executing their commands.

Can I search Codex and Claude Code sessions together?

Yes, you can search imported records across supported sources and filter by source or project.
