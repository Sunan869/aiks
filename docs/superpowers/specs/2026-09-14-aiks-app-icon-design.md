# AIKS 应用图标设计规格

- 日期：2026-09-14
- 状态：待用户规格审查
- 选择方案：A「同步核心」

## 目标

将桌面应用当前的 1×1 单色占位资源替换为可用于发行的原创图标。图标需要同时表达 AIKS 的两个核心概念：来自多种 AI 工具的会话持续同步，以及会话最终沉淀为可管理的知识。

## 视觉设计

图标采用圆角方形深色底，主图形是两段首尾相接的同步环，中央放置一个高亮知识节点。同步环表达持续、双向和增量同步；中央节点表达规范化后的知识内容，也是视觉焦点。

配色采用专业科技感方案：深海军蓝背景，青色到亮蓝、紫色的渐变作为同步环，中央节点使用近白色。图标不包含文字、字母或细碎纹理，避免在任务栏和系统托盘中失去辨识度。

建议色值：

| 用途 | 色值 |
|---|---|
| 背景起点 | `#182956` |
| 背景终点 | `#0A1024` |
| 同步环青色 | `#69F3FF` |
| 同步环蓝色 | `#478CFF` |
| 同步环紫色 | `#986BFF` |
| 中央节点 | `#E9FBFF` |

## 小尺寸规则

64 px 及以上使用完整同步环、箭头和中央加号。32 px 保留同步环和中央节点，减少渐变细节。16 px 使用更粗的轮廓与更大的中央节点，箭头只保留方向轮廓，不能依赖细线表达含义。

图标需要在深色、浅色桌面背景上都有清楚边缘。应用图标使用不透明圆角底；系统托盘需要额外检查。当前 Tauri 配置启用了 `iconAsTemplate: true`，这会将彩色图标按模板图处理，因此实现时改为 `false`，保留选定配色。

## 资源与配置

创建一份可维护的矢量母版 `apps/aiks-desktop/src-tauri/icons/icon.svg`，再使用项目已有的 Tauri CLI 从母版生成平台资源。至少包含：

- `32x32.png`
- `128x128.png`
- `128x128@2x.png`
- `icon.png`
- `icon.ico`
- `icon.icns`

当前 PNG 都是 1×1 占位文件，`icon.ico` 也是占位资源，且 `tauri.conf.json` 引用的 `icon.icns` 不存在；本次统一重建，避免不同平台出现不一致或打包失败。

仅修改上述图标资源及 `tauri.conf.json` 的 `iconAsTemplate`。不改变产品名称、窗口标题、页面配色或其他业务代码。

## 验证标准

1. 所有 Tauri 配置引用的图标文件存在且可解析。
2. PNG 实际尺寸与文件名一致，`icon.png` 为高分辨率正方形资源。
3. ICO 包含 Windows 常见尺寸，ICNS 可被 Tauri 打包流程识别。
4. 在 16、32、64 和 128 px 预览中，同步环和中央节点仍可辨认。
5. `npm run build` 成功；在环境允许时执行 Tauri bundle 或等效配置检查。
6. `git diff` 只包含本次图标相关文件，不覆盖工作区中用户现有的代码修改。

## 实现选择

最终图形是规则几何标志，适合用 SVG 精确绘制并由 Tauri CLI生成各平台位图；这样边缘、尺寸和颜色可重复，且比生成式位图更适合小尺寸应用图标。最终实现不需要引入新的运行时依赖。
