# S1.2 处理中心任务诊断：脱敏快照验收

在 Desktop「处理中心」中，先用真实会话触发一次原始同步成功而 AI 提炼失败、一次 SiYuan 编辑冲突和一次可恢复队列失败。处理中心按任务的实际持久化状态显示原因和可用操作；SiYuan 编辑冲突只能人工核查，不能自动覆盖用户原文。

点击「预览脱敏任务诊断包」，核查 JSON `schema=aiks-task-diagnostics-v2`。应包含全库统计 `counts` 与明确注明**最近最多 200 个任务样本**的 `sample`，其中有固定来源聚合、同步/AI 状态分布、故障类型数量、重试次数以及有记录的阶段延迟 p50/p95。统计字段由实际 SQLite 任务表只读投影而来，任何字段不得包含 Session ID、原始标题、路径、原文、Prompt、错误消息、密钥、模型地址、个人信息。陌生 Provider 只能归入 `unknown_source`，不能原样输出。

预览时记录当前冻结快照，在后台正常轮询任务状态变化后，旧快照不能静默改变；用户显式点击「更新预览快照」才刷新。保存和复制只能针对屏幕上当前审阅过的字节。点击「收起」必须丢弃快照；再次预览需生成新快照。

故障注入负例：在 Session 标题、Provider 来源标识、同步/提炼错误字符串中放入人工测试用 Bearer token、Windows/Linux 路径、中文敏感文本，确认它们**不出现在导出 JSON**。测试记录样本是否截断、实际失败类型是否匹配预期。前端固定测试/CI 只能验证代码安全边界；不能等同真实 Windows/内嵌 SiYuan 端到端故障恢复通过。本次不包括完整备份，S1.3 仍最后实现。
