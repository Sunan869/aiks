## 必须先通过的自动化门禁

1. GitHub 综合 CI：Desktop frontend 单元测试和 TypeScript/Vite 构建成功。
2. Windows Provider contracts 成功。
3. 在 Actions 手动运行 CI（勾选 `full_validation=true`），确保 Rust、Windows desktop compile 不再处于 skipped；记录运行 ID。
4. 用最新分支 checkout 后执行 `npm ci`、`npm test`、`npm run build`（位于 `apps/aiks-desktop`）；任何失败均不能宣称真机可验收。

## Windows 实机集中验收

| 场景 | 操作 | 通过标准 | 结果 |
|---|---|---|---|
| 个人离线隔离 | 独立 AIKS_DATA_DIR 启动，无团队认证变量 | 不触碰常用数据目录，原有离线模式可用 | 待测 |
| 窄窗口 | 主窗缩到最小可用宽度，遍历工作记录、数据源、处理中心、知识库、设置 | 无操作按钮被遮挡，列表容器内部可横向滚动 | 待测 |

| 键盘 | Tab/Shift+Tab 遍历按钮、搜索、工作记录详情 | 焦点可见、可完成业务操作，不困在非弹窗区域 | 待测 |
| 弹层层级 | 打开知识编辑，打开日期/搜索下拉框，按 Escape | 先关闭子弹层，再按 Escape 关闭父层，焦点恢复 | 待测 |

## 未完成的正式迁移

本仓库目前使用 React 18 + Tailwind 3 的自定义 `UiButton/UiInput/UiSelect` 和自维护弹层，并**未安装正式 shadcn/ui + Radix**。在具备 npm 访问与本机构建条件时，应统一安装并生成锁文件，再执行真实组件迁移和键盘/视觉回归。不能以“外观类似 shadcn”作为完成证据。
